# 음악원 「명문 음악 아카데미의 추첨 입학생」 — 소개 사이트

크랙(Crack) 스토리챗 작품의 소개 사이트다. 작품 컨셉과 그림 자료는 [docs/README.md](docs/README.md)에 있다.

## 먼저 읽을 것 — 지금 있는 것은 전부 초안이다

- 이 저장소의 사이트 파일은 Claude가 연출의 순서와 문구만 잡아 둔 **초안**이다
- **문구를 제외한 레이아웃은 GPT가 작업할 때 뜯어고친다.** 배치·크기·색·글꼴·그림·소리·움직임·코드 구조 어느 것도 유지할 필요가 없다
- 유지하는 것은 둘이다: 화면에 나오는 문구, 그리고 아래 「입장 연출 콘셉트」의 순서
- 에셋(그림·소리)과 구체적인 구현은 GPT가 맡는다. 초안에는 에셋이 하나도 없고 전부 코드로 그린 임시 그림과 합성음이다

## 입장 연출 콘셉트 (작가님 지정)

1. **어둠** — 검은 화면. 은은하게 빛나며 일렁이는 작은 오선지와 음표 하나만 떠 있다
2. **누름** — 그 음표를 누르면 연출이 시작된다
3. **악기 넷이 하나씩** — 바이올린 → 피아노 → 첼로 → 플루트 순서로 한 악기씩 소리가 난다. 소리마다 화면의 서로 다른 곳에서 음표가 어둠 속에 반짝이고, 그 뒤의 오선지가 은은하게 비친다
4. **합주** — 네 악기가 동시에 울리면서 화면이 확 밝아진다
5. **악보** — 수많은 악보가 파라라락 날아간다
6. **입장** — 그대로 사이트 본문으로 들어간다

## 초안에서 임시인 것

| 항목 | 지금 초안 | GPT가 채울 것 |
|---|---|---|
| 오선지·음표 | 코드로 그린 선 다섯 줄과 음표 하나, 다섯 자리가 같은 그림 | 그림 에셋 또는 제대로 된 그래픽 |
| 악기 소리 | Web Audio 합성음 한 음씩(라 장조 화음) | 악기별 실제 소리. `index.html` 설정의 `파일` 칸에 경로를 넣으면 합성음 대신 재생된다 |
| 악기 자리 | 화면 네 귀퉁이 근처 고정 좌표 | 자유 |
| 밝아지는 화면 | 배경색만 종이색으로 바뀜 | 자유 |
| 날아가는 악보 | 줄만 그어진 흰 종이 48장이 아래에서 위로 | 악보 그림과 날아가는 움직임 |
| 사이트 본문 | `home.html` — 「준비 중」 한 줄뿐인 빈 페이지 | 전부 |

## 문구 (유지)

- 페이지 제목: 명문 음악 아카데미의 추첨 입학생
- 음표 아래 안내: 음표를 누르면 소리가 납니다
- 건너뛰기 링크: 소리 없이 들어가기

## 초안에 넣어 둔 동작 (구현을 바꿔도 남기면 좋은 것)

- 소리는 사용자가 음표를 누른 뒤에만 난다(브라우저 자동재생 제한)
- 소리 없이 들어가는 링크가 있다
- 움직임 줄이기 설정이 켜진 기기에서는 애니메이션과 날아가는 악보를 뺀다
- 뒤로 가기로 돌아오면 입장 화면을 처음부터 다시 연다

## 파일

- `index.html` — 입장 페이지 초안. 맨 위 `설정` 객체에서 순서·간격·악기 자리·소리 파일을 바꾼다
- `home.html` — 입장 뒤에 도착하는 빈 페이지
- `docs/` — 작품 문서와 그림 자료
