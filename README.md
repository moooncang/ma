# 음악원 「명문 음악 아카데미의 추첨 입학생」 — 소개 사이트

크랙(Crack) 스토리챗 작품의 소개 사이트다. 작품 컨셉과 그림 자료는 [docs/README.md](docs/README.md)에 있다.

## 먼저 읽을 것 — 지금 있는 것은 전부 초안이다

- 이 저장소의 사이트 파일은 Claude가 연출의 순서만 잡아 둔 **초안**이다
- **문구를 제외한 레이아웃은 GPT가 작업할 때 뜯어고친다.** 배치·크기·색·글꼴·그림·소리·움직임·코드 구조 어느 것도 유지할 필요가 없다
- 유지하는 것은 아래 「방향」과 「입장 연출 콘셉트」, 그리고 본문의 문구다
- 에셋(그림·소리)과 구체적인 구현은 GPT가 맡는다. 초안에는 에셋이 하나도 없고 전부 코드로 그린 임시 그림과 합성음이다

## 방향 (작가님 지정)

- 감성 문구를 넣지 않는다. **입장 화면에는 글자가 없다.** 안내 문장·분위기 문장 모두 넣지 않고, 무엇을 누르는지는 빛과 움직임으로 알린다
- 「일레온」 사이트처럼 깔끔하고 세련되고 인터랙티브하게 만든다

## 입장 연출 콘셉트 (작가님 지정)

바탕 구조: **배경에는 처음부터 악보가 가득 깔려 있다. 그 위에 검은 그림자가 드리워져 있어서 보이지 않을 뿐이다.** 빛이 나는 것은 새로 그려지는 것이 아니라 그 그림자를 걷어 내는 것이고, 마지막에 날아가는 악보가 바로 이 깔려 있던 악보다.

1. **어둠** — 검은 화면. 은은하게 빛나며 일렁이는 음표 하나가 떠 있고, 그 둘레만 그림자가 옅게 걷혀 깔린 악보가 비친다
2. **누름** — 그 음표를 누르면 연출이 시작된다
3. **악기 넷이 하나씩** — 바이올린 → 피아노 → 첼로 → 플루트 순서로 한 악기씩 소리가 난다. 소리마다 화면의 서로 다른 곳에서 음표가 반짝이며 그 자리의 그림자를 걷어 내 악보를 비추고, **곧 꺼져 다시 어둠으로 돌아간다**
4. **합주** — 네 악기가 동시에 울리면서 그림자가 전부 걷히고 화면이 **확** 밝아진다. 깔려 있던 악보가 한꺼번에 드러난다
5. **악보** — 그 악보들이 파라라락 날아간다
6. **입장** — 악보가 걷힌 자리에서 그대로 사이트 본문으로 들어간다

### 입장 초안에서 임시인 것

| 항목 | 지금 초안 | GPT가 채울 것 |
|---|---|---|
| 깔린 악보 | 오선 묶음만 그어진 흰 종이 35장을 기울여 깐 것(코드로 그림) | 악보 그림 에셋, 까는 방식 |
| 그림자와 빛 | 검은 층을 곱하기 혼합으로 덮고, 흰 원으로 한 자리씩 걷어 냄 | 자유 |
| 음표 | 코드로 그린 음표 하나, 다섯 자리가 같은 그림 | 그림 에셋 |
| 악기 소리 | Web Audio 합성음 한 음씩(라 장조 화음) | 악기별 실제 소리. `index.html` 설정의 `파일` 칸에 경로를 넣으면 합성음 대신 재생된다 |
| 악기 자리 | 화면 네 귀퉁이 근처 고정 좌표 | 자유 |
| 악보가 날아가는 움직임 | 장마다 오른쪽 위로 돌면서 빠져나감 | 자유 |

Claude가 덧붙인 것(작가님 확인 전): 누르기 전에 마우스가 지나가는 자리의 그림자가 옅게 걷힌다.

### 입장 초안에 넣어 둔 동작 (구현을 바꿔도 남기면 좋은 것)

- 소리는 사용자가 음표를 누른 뒤에만 난다(브라우저 자동재생 제한)
- 소리 없이 본문으로 가는 링크가 있다. 화면에는 보이지 않고 키보드로 초점이 갔을 때만 나타난다
- 움직임 줄이기 설정이 켜진 기기에서는 음표의 일렁임과 날아가는 악보를 뺀다
- 뒤로 가기로 돌아오면 입장 화면을 처음부터 다시 연다

## 본문 초안 (`home.html`)

- **문구가 본체다.** 화면에 나오는 문구는 전부 `home.html` 맨 위 `내용` 객체에 있고, 이 문구는 유지한다. 그 아래 그리는 코드와 스타일은 전부 임시다
- 구성: 머리(CANTOREUM · 작품 제목 · 한 줄 소개) → BRIEFING → WORLD → SALONS → CALENDAR → CAST → START → 성인 표기
- 섹션 라벨은 영문, 본문은 한국어 존댓말의 완결된 문장이다. 과장 부사와 분위기 문장을 쓰지 않았다
- 인물 소개에는 모티브 음악가 이름을 글로 적지 않았다(첫등장 카드 그림에만 별명이 있다)
- 그림은 `docs/`의 자료를 그대로 불러 쓴다: 머리에 배경 배너 `C1`, 살롱에 `S1~S4`, 인물에 첫등장 카드 12장. 사이트용으로 줄인 변환본은 아직 없다
- 크랙 작품 주소가 아직 없어 PLAY 버튼은 나오지 않는다. `내용.크랙주소`에 주소를 넣으면 나온다
- 넣지 않은 것: 인물별 표정 그림 보기, 배경 36곳 둘러보기, 플레이 가이드, BGM

## 파일

- `index.html` — 입장 페이지 초안. 맨 위 `설정` 객체에서 순서·간격·악기 자리·소리 파일을 바꾼다
- `home.html` — 본문 페이지 초안. 맨 위 `내용` 객체에 문구와 그림 경로가 있다
- `docs/` — 작품 문서와 그림 자료
