# 음악원 「명문 음악 아카데미의 추첨 입학생」 — 인수인계

이 폴더에서 작업을 이어받는 사람과 AI(Claude 새 채팅, ChatGPT 등)는 이 문서를 먼저 읽는다.
기준일 2026-11-23. 작성 Claude. 문서 끝의 「10. 작업 기록」에 고친 내용을 한 줄씩 남긴다.

## 0. 한 줄 요약

작가님(필명 문창놈)이 AI 스토리챗 서비스 **크랙(Crack)** 에 올릴 현대 클래식 음악 아카데미물 「명문 음악 아카데미의 추첨 입학생」의 제작 자료다. 약칭 「음악원」, 작품 코드 `MU`. 유저가 세계 최고의 음악 아카데미 칸토레움에 심사 없이 제비뽑기로 들어온 '추첨 입학생'이 되어, 음악사의 거장을 모티브로 한 12인과 얽히는 작품이다.

**이 작품은 게임·시뮬보다 스토리텔링 쪽이다(작가님 지정 11-22).** 인물 관계와 사건이 중심이고, 정보창은 간단하게 둔다. 수치·단계 관리와 합주 기능은 넣지 않는다.

지금 상태: 메인 프롬·캐릭터 키워드북·NAI 태그시트가 있고, 인물 이미지 240장이 뽑혀 이름이 붙고 webp로 바뀌어 있다(`CS\`). 첫등장 카드 12종과 도트 배경 배너 36종의 PNG·WebP도 완료했다. 여성 H씬 80장도 뽑혀 이름이 붙고 webp로 바뀌어 있다(`H씬\`). 시작 프롬(히든)·프롤로그·단축어·플레잉 가이드·남성 H씬 그림은 아직 없다(남성 H씬은 태그까지 있다). 크랙 빌더에는 아무것도 넣지 않았다.

## 3. 크랙 기본 지식 (처음 보는 AI용)

크랙은 뤼튼의 AI 챗 서비스다. 제작자가 작품을 등록하면 유저가 그 설정 위에서 AI와 역할극을 한다.

- **설정 프롬프트(메인 프롬)**: 7,000자. 매 응답마다 AI에게 들어가는 본체
- **키워드북**: 항목당 400자. 등록한 키워드가 대화에 나오면 그 항목이 추가로 들어간다. 동시에 켜지는 수에 제한이 있어 키워드가 서로 겹치면 엉뚱한 항목이 켜진다
- **시작 프롬(히든)**: 모드별 1개, 1,000자. 유저에게 안 보이는 첫 장면 지시문
- **프롤로그**: 모드별 1개, 1,000자. 유저가 처음 보는 첫 메시지(그대로 출력되는 글)
- **단축어**: 작품당 20개. 이름 10자 / 설명 30자 / 본문 400자
- **플레이 가이드**: 500자. 유저에게 보이는 안내
- 글자 수는 **띄어쓰기와 줄바꿈까지 센다.** 어림하지 말고 반드시 프로그램으로 잰다(python `len()`)
- 이미지는 AI가 응답에 마크다운 `![](주소)`를 써서 띄운다. 그래서 메인 프롬에 주소 규칙과 코드 목록이 들어 있다

## 4. 작성 규칙 — 작가님 방식

### 4-1. 일하는 방식
- 호칭은 「작가님」, 존댓말. 답은 짧고 실무적으로
- 파일을 고치면 **고친 파일을 바로 다시 준다.** 글자 수는 실측해서 숫자로 보고한다
- 작가님은 자주, 정확하게 정정한다. 바로 반영하고, 반려된 안은 다시 꺼내지 않는다
- **빼라고 하면 빼기만 한다.** 뺀 자리에 다른 지시문을 채워 넣지 않는다
- 한 파일을 고치면 연동 파일도 같이 고친다: 외형 → 키워드북·메인 프롬·태그시트 / 인물 관계 → 키워드북·메인 프롬 #11 `[사이]`
- 작업용 스크립트·중간 파일을 이 폴더에 남기지 않는다

### 4-2. 프롬 형식(메인 프롬·키워드북·시작 프롬)
- 구조: `# N.제목` + `-` 불릿 + `[대괄호]` 묶음 + ` ·` 하위 항목
- 압축 표기: 띄어쓰기 최소, 漢字(每·禁·必·無 등)는 글자 수 줄이는 용도로만. 기호 `✕`금지 `○`허용 `必`필수 `無`없음 `→`순서, `ⓤ`=유저 `ⓒ`=캐릭터
- **AI의 출력은 한글·정상 띄어쓰기만**
- 마크다운 표 금지. `**`는 대사 형식 `**이름**｜"대사"`에만. `---`를 글 바로 다음 줄에 붙이지 않는다
- **예시는 형식만.** 정보창 양식에 실제 값을 넣으면 AI가 그대로 베낀다

### 4-3. 내용 원칙
- 프롬은 **진행 속도·등장 빈도·발동 조건을 정하지 않는다.** 줄거리도 넣지 않는다. 세계·구성 요소·문체·운영 규칙만
- ⓤ 대필 금지. ⓤ가 밝힌 전공·실력·경력은 깎지 않고 그대로 받는다. 어려움은 듣는 귀·한정된 자리·사람 사이에서 나온다
- 긍정편향 금지(자유 모드만 허용) — 단 부정편향으로 읽히지 않게 쓴다
- 난이도는 「어렵다」 같은 말이 아니라 규칙으로 적는다(시작 조건 / 애매할 때의 판정 / 기한 / 누가 먼저 움직이나)
- **이 작품만의 원칙(11-22)**: 스토리텔링이 먼저다. 정보창에 수치·단계표를 늘리지 않는다. 합주를 「기능」으로 만들지 않는다(함께 연주하는 장면은 이야기 안에서 그냥 일어난다)
- 외형은 뽑힌 그림이 기준이다. 외형 서술은 담담한 참고 정보로만
- 등장인물은 전원 성인(20세 이상)
- 실명은 사후 70년이 지난 작곡가와 그 곡 이름, 나라 이름만. 연주자·음악원·콩쿠르·기획사·악기 브랜드는 전부 가상. 가사·악보는 옮겨 적지 않는다
- 모티브 음악가의 이름은 제작 문서(챗 방향성·이 문서)에만 둔다. 프롬·키워드북에는 성격·버릇·대표곡으로 풀어 적고, 환생·후손 설정은 쓰지 않는다
- 첫등장 카드의 예외(작가님 지정 11-22): 모티브 음악가의 이름을 넣어 「베토벤의 재림」 같은 별명으로 표기한다. 사야카는 「클라라 슈만의 재림」, 로완은 「슈만의 재림」. 카드의 별명 표기이며 프롬·키워드북의 환생 설정을 바꾼 것은 아니다

### 4-4. NAI 태그 규칙
- 태그시트에는 품질·인원수(1girl 등)·nsfw·작가 태그를 넣지 않는다. 그림체는 작가님 베이스 칸에 있다(「NAI 실사용 설정」)
- 인물 베이스에는 외모·의상·착용 소품만. 표정·자세·손에 드는 물건은 표정 줄에만
- 당황 표정은 `flustered`를 쓰고 홍조 태그는 넣지 않는다. 강조는 `1.2::tag::`(반드시 `::`로 닫는다)
- 이 작품에서 정해진 것
  - 「한 뭉치」 = 인물별로 베이스·자연어·표정·분위기가 다 든 블록 하나. 한 번에 복사할 수 있어야 한다(공통 연출 모듈이 아니다)
  - 표정 줄은 통째로 `1.5::…::`로 감싼다
  - **2 평소와 4~10 감정 표정에는 손에 쥐는 물건(컵·악보·연필·카드·사탕·악기·지휘봉·우산·수첩)을 넣지 않는다.** 손에 드는 물건은 1 첫등장·3 연주·11 무대 연주에만
  - 귀에 펜을 꽂는 태그는 쓰지 않는다
  - 학생 9인의 옷은 제복이 아니라 비슷한 톤의 사복(깃 있는 흰 셔츠·블라우스 + 검은 하의 + 겉옷 한 벌)
  - 평소 배경은 연습실이고, 피아노 자리에 그 인물이 다루는 악기를 넣는다(로완만 살롱으로 뽑혔다)
  - 무대 연주(필살기)의 연출은 손에 든 것이 아니라 공간에서 나오게 한다 — 마테이의 지휘봉에 번개를 붙였다가 「전기봉을 휘두르는 느낌」이라는 지적을 받고 밤하늘로 바꿨다

## 5. 작품 확정 설정 (정본은 메인 프롬)

### 5-1. 장르·톤·배제
- 현대 + 클래식 음악 + 아카데미(전원 성인) + 군상극 + 19+ 남성향. 로맨스는 서브플롯, 본축은 인물 관계와 사건
- 문체: 담백한 3인칭 관찰자. 소리를 형용사로 설명하지 않고 몸과 공간으로(손·호흡·활·페달·홀의 잔향·객석의 기척). 곡 해설·음악사 강의 없음
- 배제: 회귀·빙의·상태창·시스템·초능력 / 음모 떡밥·엔딩 설계 / AI가 먼저 꺼내는 손 부상·청력 상실·불치병 / 한 번 듣고 다 같이 감탄하는 사이다 / 등록 인물 억지 호출 / 수치 관리·합주 기능

### 5-2. 세계

- 칸토레움: 세계 최고로 꼽히는 음악 아카데미. 3년 과정, 입학 자격 만 20세 이상. 한 해 40명(실기 선발 39 + 추첨 1), 재학 120명

### 5-3. 추첨석 — 제목의 축
- 설립자 유언으로 정관에 박힌 자리. 해마다 한 사람은 심사 없이 제비로 뽑는다(자격은 만 20세 이상뿐)

- 눈초리는 말·시선·자리 배정까지다. 모함·악보 훼손·폭력으로 번지지 않는다
- 귀는 정직하다. 연주로 보인 것은 듣는 사람마다 제 기준으로 받아들이고, 한 번에 다 같이 돌아서지 않는다

### 5-4. 무대·살롱·사건 (메인 프롬 #5)
- 무대 급: 연습실 → 살롱 → 리사이틀홀 → 대극장 → 바깥. 자리는 한정돼 있다
- 곡은 하룻밤에 되지 않는다. 무대에서 나오는 것은 연습·레슨 장면이 쌓인 만큼
- 살롱은 ⓤ의 연주·행동에 제 미학으로 따로 반응한다(단계표는 없다)
- 사건 = 사람 사이에서 생기는 일. ⓒ의 바람·이해·사이에서 나오고, ⓤ 없이도 진행되며, 끝나면 자국(관계·평판·자리·소문)을 남긴다

### 5-5. 시작 모드 (메인 프롬 #14)

- ♯ 수석 입학(이지): 애매하면 성공. 전액 장학·기숙사 무료·생활비 지급, 지도교수를 고름, 네 살롱 모두 초대. 루이제가 ⓤ에게 수석을 내준 차석이 된다
- ♮ 자유: 신분·전공·처지를 ⓤ가 정한 대로. 시도로 보지 않고 쓴 대로 이루어진다. 긍정편향 허용

- 추첨생을 보는 눈과 호칭의 '추첨'·'제비'는 ♭에서만 ⓤ에게 향한다. 다른 모드에서는 엑스트라 추첨생에게 간다

## 6. 이미지 체계

### 6-1. 주소 (메인 프롬 #3)
- 배경 `https://cjivip.uk/MU/B/{배경코드}.webp`
- 인물 `https://cjivip.uk/MU/CS/{인물코드}_{번호}.webp` — 올릴 파일은 `CS\`의 240장

### 6-2. 배경 코드 36종 (메인 프롬 #3①) — PNG·WebP 제작 완료
- 학내: C1 정문·중정 / C2 복도 / C3 연습실 / C4 레슨실 / C5 강의실 / C6 악보고 / C7 악기 공방 / C8 식당·카페 / C9 기숙사
- 살롱: S1 우르텍스트 / S2 브라부라 / S3 아리오소 / S4 누오바
- 무대: T1 리사이틀홀 리허설 / T2 리사이틀홀 본공연 / T3 대극장 리허설 / T4 대극장 본공연 / T5 무대 뒤·대기실 / T6 객석 / T7 오케스트라 연습실
- 도시: L1 호숫가 / L2 광장 / L3 오페라극장 / L4 카페 / L5 주점 / L6 성당 / L7 역 / L8 셋방 / L9 저택
- 범용: U1 길 / U2 밤거리 / U3 공항 / U4 열차 / U5 호텔 / U6 타국 홀 / U7 녹음실
- 만드는 법은 「배경 배너 GPT 프롬프트」. 3200×640(5:1) 배너, 파일명 = 코드. PNG는 `배경 배너\`, webp(품질 95)는 `배경 배너\webp\`에 있다. `MU/B/` 업로드는 아직 하지 않았다
- 디자인은 첫등장 카드와 같은 계열이다: 테두리·명패 없이 왼쪽 먹빛 여백에 작은 글씨와 큰 명조 제목, 묶음별 강조색의 사선 색면과 가는 호. 영지물식 양피지 테두리는 쓰지 않는다
- 작가님 추가 지시(11-23): 건물 전경을 보여 주려 하지 말고 영지물 F1 견본처럼 소품과 공간 일부로 장소의 느낌을 표현한다. 그림체는 픽셀 경계와 덩어리 명암이 보이는 도트 감성으로 변경했다
- 사람은 그리지 않는다. T2·T4·T6의 관객만 얼굴 없는 실루엣이고 무대 위는 늘 비워 둔다. T1·T2와 T3·T4는 무대 위에서 객석을 본 같은 시점의 짝(리허설 = 빈 객석, 본공연 = 찬 객석)
