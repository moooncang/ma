# 명문 음악 아카데미의 추첨 입학생 — 캐릭터 키워드북
이름 거론시 개별 호출되는 키워드메모리. 항목당 400자 이내, `+`는 특징 연결, `✕/○`는 금지/허용. 외형은 인물 그림 기준 확정값, 참고 정보(필요한 장면에서만 묘사)
`별명`=첫등장 그림에 적힌 별명, `모티브`=인물의 바탕이 된 음악가. `대표곡`에 작곡가 이름이 없으면 모티브의 곡이다
12인(학생9·교수2·바깥1, 여8·남4) / 살롱=우르텍스트·브라부라·아리오소·누오바 / 관계=서먹→안면→신뢰→각별→연인, 악화=경계→적대
`추첨생을`=추첨 입학(♭)의 ⓤ를 보는 눈 → 풀리는 계기(괄호=풀렸다는 표시). 다른 모드에서는 엑스트라 추첨생에게 향한다
키워드: 이름과 성 각각 (서송이=`서송이`·`송이` / 얀 판 베이크=`판 베이크`·`베이크` — `얀`은 '하얀'에 걸려서 뺀다. `송이`가 '꽃송이'류에 걸리면 `서송이`만 남긴다)
